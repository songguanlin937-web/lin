# Word Card

Word Card 是一个开源 Codex skill，可将文章整理成便于学习和复习的知识卡片。

## 解决的问题

阅读文章时，重点分散在不同段落，不易快速提炼和回顾。Word Card 帮助读者从文章中筛选关键知识，整理成简短、独立且易复习的卡片。

## 主要功能

- 将用户粘贴的文章整理为 **5–8 张**知识卡片。
- 每张卡片包含**标题、核心知识、例句**。
- 默认使用文章原语言，并以原文为依据，避免重复要点和无依据的信息。

## 安装方法

在项目根目录执行以下命令，将 skill 安装到 Codex 的个人 skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R . ~/.codex/skills/word-card
```

如果 Codex 尚未识别新 skill，请重新加载或重启 Codex。

## 使用方法

在 Codex 对话中输入 `$word-card`，然后粘贴文章；也可以直接提出“把这篇文章整理成知识卡片”并附上文章内容。需要其他输出语言或卡片数量时，可在请求中说明。

## 输入输出示例

**输入：**

> 番茄需要充足阳光和排水良好的土壤。移栽后应浇透水，之后等土壤表层变干再浇。给植株搭支架可以避免果实接触地面。成熟的番茄会从绿色变为红色，应及时采摘。轮作有助于减少土壤病害。

**输出：**

### 1. 光照与土壤
- **核心知识：** 番茄适合在阳光充足、排水良好的土壤中生长。
- **例句：** 把番茄种在每天都能晒到太阳且不积水的位置。

### 2. 移栽后浇水
- **核心知识：** 移栽后先浇透水，之后根据土壤表层干湿情况浇水。
- **例句：** 移栽当天浇透水，等表土变干后再补水。

### 3. 搭建支架
- **核心知识：** 支架能托住植株，避免果实接触地面。
- **例句：** 番茄长高后用支架支撑枝条，让果实离开地面。

### 4. 适时采摘
- **核心知识：** 番茄成熟时会由绿色变红，应及时采摘。
- **例句：** 看到果实转红，就可以及时采下。

### 5. 轮作
- **核心知识：** 轮换种植作物有助于减少土壤病害。
- **例句：** 下一季在番茄地改种其他作物，帮助降低土壤病害风险。
